PD Save Editor — диагностика на Windows
=======================================

1. Положите в эту папку PDSaveEditor-windows-x64.exe — со страницы Releases на GitHub.
   Если exe лежит в «Загрузках», скрипт найдёт его и там.

2. cleanup.bat  — уборщик: закрывает редактор и удаляет его служебные данные
   (%APPDATA%\PDSaveEditor, кэш окна, остатки распаковки в %TEMP%\_MEI*).
   Сохранения игры НЕ трогаются. Старый лог перед удалением копируется в reports\.

3. debug.bat    — автодебаг: собирает сведения о системе (Windows, видеокарта,
   WebView2, .NET, антивирус), дважды запускает редактор с подробным логом
   (только сервер; затем с окном), снимает лог редактора и журнал событий Windows
   и упаковывает всё в reports\pdsave-debug-ДАТА.zip.

4. Пришлите этот zip.

Порядок: cleanup.bat -> debug.bat -> отправить zip.
Скрипты ничего не устанавливают и не меняют, кроме снятия пометки «скачано из интернета»
с exe редактора (Unblock-File) и удаления данных редактора уборщиком.
